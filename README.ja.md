# opendata-japan

本プロジェクトは、日本の地方公共団体におけるオープンデータの取組状況を可視化するインタラクティブなダッシュボードを提供します。令和6年度「地方公共団体におけるオープンデータの取組に関するアンケート」のデータを使用し、インタラクティブなカラム地図（Tabular Maps）上に表示します。

## ライブデモ

- **[オープンデータ取組状況ダッシュボード (Open Data Initiative Status Dashboard)](https://code4fukui.github.io/opendata-japan/)**

## 機能

- **インタラクティブなカラム地図**: ダッシュボードは日本をグリッド状に配置した地図を表示します。全国表示から各都道府県へとドリルダウンできます。
- **色分けされた状況表示**: 各地方公共団体はアンケートの回答に基づいて色分けされます:
    - **赤**: アンケート未提出または未確認。
    - **ピンク**: 提出済だが、現在オープンデータに取り組んでいない。
    - **白**: 提出済かつ、オープンデータに取り組んでいる。
- **都道府県レベルの集計**: 全国表示では、各都道府県のアンケート提出率に基づいたヒートマップと、提出率および取組率の統計を表示します。
- **詳細データ表示**: 特定の地方公共団体をクリックすると、アンケートの全回答を含む表が表示されます。

## データソース

可視化は以下のデータに基づいています:

- **主なデータ**: デジタル庁 [令和6年度地方公共団体におけるオープンデータの取組に関するアンケート](20250210_resources_data_questionnaire_outline_04.csv)
    - [公式メタデータと説明](20250210_resources_data_questionnaire_outline_05.md)
- **補足データ**: 日本の地方公共団体の網羅的なリストとして [code4fukui/localgovjp](https://github.com/code4fukui/localgovjp) を使用。

## 仕組み

このダッシュボードは、標準のHTML、CSS、JavaScript（ESモジュール）で構築された静的Webアプリケーションです。

- `index.html` は、ブラウザ上で直接アンケートデータと地方公共団体データ（CSVファイル）を取得します。
- 可視化には、地理的領域をレスポンシブなグリッドに配置するカスタムのカラム地図エンジン（`makeGrids.js`）を使用しています。
- 提出率、取組率、色分けの計算はすべてクライアントサイドで行われます。
- アンケートのCSVを事前処理し、各列とそのユニークな値を記述したメタデータファイル（`.meta.csv`）を生成するためのDenoスクリプト（`makeMeta.js`）が含まれています。

## ローカルでの開発

ダッシュボードをローカルで実行するには:

1. **リポジトリのクローン:**
    ```sh
    git clone https://github.com/code4fukui/opendata-japan.git
    cd opendata-japan
    ```

2. **ローカルWebサーバーの起動:**
    静的サイトであるため、任意のシンプルなHTTPサーバーを使用できます。

    Node.jsを使用する場合:
    ```sh
    npx http-server
    ```
    または、Python 3を使用する場合:
    ```sh
    python -m http.server
    ```
